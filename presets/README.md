# プリセット一覧

通常12種類・異常12種類。各JSONはフォームで編集・保存できます。認証情報は含みません。

## 01-normal / 正常 / 指図API / 固定200件

【想定】
MES/ERPの定期取得・ページング・差分収集の検証。指図API / 固定200件を想定。

【生成内容・条件】
更新周期1000ms、最大tick数無制限。
ordersを200件で初期化。
1tickごとに各コレクション最大2件を更新。既定ページ100件、カーソル寿命600秒。

【確認事項】
ページ間でIDの欠落・重複がないか、snapshotを保持して全件取得できるかを確認。
最終ページのdeltaリンクで更新と削除を取得。429はRetry-After、期限切れカーソルは再同期を確認。

【実行前】
公開・認証・送信先は別のプロファイルで指定し、保存後に停止・開始して適用。各条件はフォームとJSONで編集可能。
